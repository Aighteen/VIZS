# Track decision — tailored to shopping assistant

## Title track (exactly one)

**Recommended: VISA — Reimagine Shopping.** The team builds a generative-AI-assisted commerce experience for the *decision-making* stage: credible seller/price evidence and purchase guidance via natural language. Verify any sponsor-specific judging/submission details before checking the box.

Why not default to **Cook Smarter**? Although it uses AI agents and automation, the product's value proposition centers on **shopping decisions**. VISA is the clearer fit, provided all Visa rules are met. The human team makes the final choice.

## Sponsored side tracks (at most three)

| Option | Fit | Eligibility gate | Recommendation |
|---|---|---|---|
| **Photon — Build a Messaging Agent using Photon 2.0** | Direct: SMS shopping assistant | Actually built on Photon 2.0 and live on at least one Photon channel | **High-priority candidate** if beta access works |
| **VEYZL** | AI risks, evidence/prompt injection | Real GitHub-connected PR audit, visible finding/fix before vs after | Optional if integration is fast; otherwise skip |
| **SideShift startup idea** | Strong consumer need and potential distribution | Real business story; supplied terms do not require SideShift API | Optional if pitch is good, no new infrastructure |
| **T-Mobile phone shopping** | Shopping category but wrong vertical | Must solve specified phone-shopping direction and use provided requirements | Skip unless team pivots from fragrances |
| **SpaceXAI** | Grok use alone is insufficient | Cursor + Grok Imagine or Voice API + sponsor space-data focus | Do **not** claim eligibility for basic Grok text use |
| **Perceptron** | Doesn't fit SMS text shopping MVP | Their perception/robotic API and relevant task | Skip |

## Non-sponsored tracks

DubHacks NEXT may fit if the team can explain real users, acquisition, and revenue potential. Additional awards such as MLH Gemini/Backboard require meaningful eligible API use; do not add an API just to collect track labels. The freshman-only beginner track is only for all-freshmen teams.
