VIZS seller check: settings

Pair this extension with your local VIZS backend. The pairing token stays in this browser profile's extension storage and is only read by the extension's service worker, never by web pages.

Allowed: http://127.0.0.1:<port>, http://localhost:<port>, or an https:// address. Default http://127.0.0.1:8000.

Run python -m app.workflow.dev_server --pair in the backend checkout, then copy the value of VIZS_EXTENSION_TOKEN from the root .env.

What VIZS sends

Only when you click Check seller on the pet: the address of the current tab and the optional price you typed. VIZS does not read page content, payment forms or your browsing history, and stores only these settings and the pet's position.
